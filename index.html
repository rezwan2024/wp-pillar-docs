Everything a real plugin needs

Not a toy scaffold — the exact patterns used by production plugins today.

🗄️

Eloquent ORM

Zero $wpdb. Full query builder, relationships, model events, and migrations — the same Illuminate packages that power Laravel.

🧭

Laravel-style Routing

Clean REST API routes with automatic nonce verification, route groups, and a right-to-left middleware pipeline.

🔒

Security by Default

Nonce checks, permission Policies, PHP/WordPress version guards, and safe uninstall are part of the framework core — never optional.

📦

IoC Container

Dependency injection inside WordPress, fully isolated per plugin slug — two WP Pillar plugins never step on each other’s config.

🛡️

Multi-plugin Safe

A shared Eloquent Capsule with named, per-plugin connections and namespace-based auto-routing — no cross-plugin data leaks.

⚡

Modern Frontend Ready

Build full SPAs with Vue 3 or React inside wp-admin. Hash-based routing, Vite production builds, zero Gutenberg conflicts.
